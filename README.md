# Round Robin CPU Scheduling

Homework for an **Operating Systems** course implementing the **Round Robin** CPU scheduling algorithm in **C++**.

## Overview

A console application demonstrating the Round Robin scheduling policy — the classic time-slicing algorithm used by many operating systems — showing process arrival, queueing, and turnaround / waiting times.

## Repository Structure

```
├── src/          # C++ source
└── makefile      # Build configuration
```

## Features

- Round Robin scheduling simulation
- Process time-quantum handling
- Build via makefile

## Tech Stack

C++, operating systems, scheduling algorithms.
